# Workspaces

A workspace is an isolated environment containing its own servers, tool calls, analytics, alert rules, members, and API keys. Think of it as a project or team boundary.

## Workspace types

| Type | Description |
|------|-------------|
| **Personal** | Created automatically on signup. For individual use. Cannot be renamed, deleted, or shared. |
| **Org** | Created manually. Can have multiple members with different roles. Used for team or product deployments. |

## Creating a workspace

Click the workspace name in the sidebar → **New workspace**. You can only create a new org workspace if you're not already in one (one org workspace per user).
