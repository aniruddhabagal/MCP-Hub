# Personal vs Org Workspaces

## Personal workspace

Created automatically when you sign up. Intended for individual use and experimentation.

**Constraints:**
- Cannot be renamed
- Cannot be deleted
- Cannot have other members invited to it
- One per user, always

Use your personal workspace for:
- Learning MCPHub
- Testing a server registration before adding it to a team workspace
- Personal projects with no team collaboration needed

## Org workspace

Created manually. Designed for team or product deployments.

**Capabilities:**
- Custom name and URL slug
- Multiple members with different roles (member, admin, owner)
- Multiple API keys
- Can be renamed or deleted by the owner

**Constraint:** You can only be in one org workspace at a time. If you're already in an org workspace, the "New workspace" button is disabled. To join another org workspace, accept an invitation.

## Switching between workspaces

Use the workspace switcher in the top of the sidebar. Your last active workspace is persisted across sessions, so you won't need to switch every time you log in.
